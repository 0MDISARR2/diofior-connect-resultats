# Diofior Connect · Résultats

Plateforme web des résultats de **Diofior Connect**, application mobile SIG participative qui mesure la couverture du réseau mobile dans la commune de Diofior (Sénégal).

- **Carte** : qualité du signal par hexagone de 250 m, filtrable par opérateur et par réseau.
- **Opérateurs** : comparaison Orange, Yas et Expresso (qualité, 4G/3G/2G, signal médian, débit).
- **Zones** : avancement de la collecte et zones de signal faible.
- **Participation** : mesures et téléphones participants par jour.
- **Méthode** : données collectées, seuils, nettoyage, limites.

Le site lit uniquement des résultats agrégés (au moins 3 mesures par hexagone) via des fonctions publiques Supabase. Aucun point individuel n'est publié.

Site statique (HTML, Leaflet, Chart.js) hébergé sur GitHub Pages. Fond de carte et contour de la commune : © contributeurs OpenStreetMap (ODbL).
